# Практическая работа 1

Типы данных, арифметика и корректный расчёт показателей

Исходный проект намеренно неполный. TODO обозначают места, которые необходимо завершить. Не исправляйте код случайным подбором до прохождения SelfCheck.

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr01.SelfCheck
```
